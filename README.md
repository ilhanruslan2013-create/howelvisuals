# HowelVisuals (Fabric 1.21.4, client-side)
Сборка: установите JDK 21, затем в папке проекта `gradle wrapper && ./gradlew build`.
Готовый .jar будет в build/libs/howelvisuals-1.0.0.jar -> положить в папку mods (нужен Fabric Loader + Fabric API).
Right Shift - показать/скрыть все визуалы. Остальные клавиши назначаются в Настройки -> Управление -> HowelVisuals.
